# Web Development Tasks - SkillCraft Technology

A comprehensive front-end web development project implementing 4 essential tasks using pure HTML, CSS, and JavaScript.

## 📌 Project Overview

This repository contains the completed tasks for the SkillCraft Technology Web Development Internship, organized into a clean, single-page responsive web application:

1. **Task 01: Responsive Landing Page & Navigation Menu**
   - Fixed navigation bar that remains accessible across all sections.
   - Dynamic style, shadow, and background transitions on scroll.
   - Interactive hover states on navigation links.
   - Fully responsive layout for mobile and desktop screens.

2. **Task 02: Stopwatch Web Application**
   - Accurate digital time tracker (`HH:MM:SS.CS`).
   - Core controls: Start, Pause, and Reset.
   - Lap recording system displaying a chronological list of lap times.

3. **Task 03: Tic-Tac-Toe Web Application**
   - Two game modes: **Player vs Player** (local 2-player) and **Player vs Computer** (AI).
   - Real-time turn indicator and victory/draw condition checks.
   - Persistent scoreboard tracking Player X wins, Player O wins, and Draws.
   - Instant board reset option.

4. **Task 04: To-Do Web Application**
   - Task creation with custom title, date, and time.
   - Completion toggle with visual strikethrough.
   - In-place editing of task text and due dates.
   - Single task removal and bulk clearing of completed tasks.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic page layout and structure.
- **CSS3**: Responsive design, custom color themes, flexbox, and grid.
- **JavaScript (ES6+)**: DOM manipulation and application logic.
